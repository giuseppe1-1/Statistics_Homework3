# Penetration scores of n systems and m attackers (LLN and CLT)

Static page (HTML + CSS + JavaScript, no build step, no dependencies). All simulations run in the browser.

## Files
- `index.html` - page structure and text
- `style.css` - styles (dark theme)
- `js/sim.js` - simulation engine: random generator, Bernoulli and Rademacher walks, statistics, exact tail probabilities, Kolmogorov-Smirnov distance
- `js/app.js` - user interface, charts and tables
- `penetration-site.zip` - everything above, used by the "Download all files" button
